
# DocuPilot

DocuPilot is a version-aware technical documentation assistant
that retrieves evidence from user-selected documentation sources
and generates answers with verifiable citations.

## Project status

Under active development.

## Planned capabilities

- Register and index multiple documentation URLs
- Retrieve evidence from selected sources
- Generate citation-backed answers
- Abstain when evidence is insufficient
- Evaluate retrieval quality, grounding, reliability and latency

## Development

The application uses Python, FastAPI and Docker Compose.
See `docs/architecture.md` for the planned system design.

Evaluation methodology and verified results will be published
as implementation and experiments progress.
